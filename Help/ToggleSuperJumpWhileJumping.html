Toggle Super Jump While Jumping

With this checked, pressing the Up Key (typically Space) will immediately activate the Jump Power for as long as it is held down, and deactivate it when the key is released.

This differs from Jump Mode in that Jump Mode automatically jumps while pressing any movement key. This feature doesn't do that, and is presented as an alternative to full-on Jump Mode.

This only works while Speed on Demand is active, and only in Sprint, Speed, or Non-SoD Modes.

If a Speed power is active, it will be temporarily toggled off while jumping, and re-enabled when the Up key is released.

Though this is a fun and quick way to get around, especially when paired with a Speed power, it might require some practice to avoid taking falling damage from releasing the Up key too early and switching off the Jump power in mid-air.
